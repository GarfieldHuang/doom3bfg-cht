# 術語表

台灣用語。原則：**人名一律保留英文**；組織縮寫（UAC、PDA、BFG、EnPro、Mars-Sec）保留英文；
地名、怪物、武器、物品譯成中文。同一個詞在全部譯文中只用一種譯法。

## 稱謂

| 英文 | 譯法 |
|---|---|
| Dr. X | Dr. X（不譯，例：Dr. Betruger） |
| Sgt. X / Sarge | X 中士 / 中士（Sarge 指 Sergeant Kelly 時譯「中士」） |
| Lt. X / Cpl. X / Pvt. X | X 中尉 / X 下士 / X 二等兵 |
| Marine | 陸戰隊員（指玩家時也用這個） |
| Marine Command | 陸戰隊司令部 |
| Executive Counsel | 執行顧問 |
| Director | 主任 |
| Mars-Sec / Security | Mars-Sec / 保全 |
